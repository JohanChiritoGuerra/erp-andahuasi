UnidadLTS
El ítem se registra como consumo común. No aporta nutrientes al cálculo de fertilización y no requiere composición ni ficha técnica.
1Presentación

La unidad de almacén (LTS) no define si el producto es sólido o líquido: tú lo eliges.

Unidad de salida LTS: 1 unidad = 1 L de producto. Con g/L o % p/v el aporte se calcula por litro; la densidad solo se pide si usas % p/p.

Unidad de salida LTS: el aporte se calcula por kg de producto con % p/p.

2Composición nutricional

Copia el valor del elemento puro que aparece en la ficha o en la plantilla Excel (ej. 43 % K, 33 % N). Si la etiqueta dice óxido (K₂O, CaO, P₂O₅), conviértelo antes. Para % usa máximo 100; para g/L máximo 2000.

Aún no se configuró composición. Agrega el primer elemento desde la etiqueta o ficha técnica.

Fichas con óxidos

Si la etiqueta expresa el contenido como óxido, multiplica el valor por el factor para obtener el elemento puro que se registra en la composición.

En la fichaFactorRegistrar como
K₂O× 0.830K
P₂O₅× 0.436P
CaO× 0.715Ca
MgO× 0.603Mg
SO₃× 0.400S
B₂O₃× 0.311B
Ejemplo: 46 % K₂O × 0.830 = 38.2 % K
